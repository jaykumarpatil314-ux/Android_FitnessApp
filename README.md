Android_FitnessApp

A Native **Android Mobile Application** developed in **Java** for the **Mobile & Web Application Development Internship (Task 3)**, integrated with the **Java REST Backend**.

![Android](https://img.shields.io/badge/Platform-Android%20%7C%20Java-3DDC84?style=for-the-badge&logo=android)
![Backend](https://img.shields.io/badge/Backend-Java%20HTTP%20REST-orange?style=for-the-badge&logo=openjdk)

---

## 🌟 Mobile Features

- 📊 **Dynamic Fitness Dashboard**: Visual Android progress bars for Daily Steps, Calories Burned, Workout Time, and Water Hydration.
- ⚡ **One-Tap Quick Loggers**: `+500 Steps` button and `+1 Glass Water` button.
- 🏋️ **Manual Workout Logger**: Dialog to log workouts (Running, Cycling, Gym, Yoga, HIIT) with duration and calories.
- 🕒 **Recent Activities Feed**: Displays logged exercises in real time.
- 🌐 **Java Backend Synchronization**: Syncs activities with `CodeAlpha_Java_Backend` running on port 8080 (`http://10.0.2.2:8080/api/fitness`).

---

## 🚀 How to Run in Android Studio

1. Open **Android Studio**.
2. Select **File > Open...** and select `CodeAlpha_Android_FitnessApp`.
3. Allow Gradle to sync.
4. Run on an Android Emulator or connected physical phone.
